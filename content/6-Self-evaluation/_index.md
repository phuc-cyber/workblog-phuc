# Self-Assessment

While completing the workshop and developing the **Car Parking** project, I had the opportunity to apply academic knowledge to a practical product. My responsibilities extended beyond programming to requirement analysis, frontend, backend and database preparation, functional testing, exploration of an AWS deployment architecture, and completion of the project report.

The project gave me a clearer understanding of how the components of a system work together, from the user interface and APIs to data storage and deployment infrastructure. It also strengthened my ability to study unfamiliar technologies independently, troubleshoot issues, manage progress, and document a technical process with written explanations and supporting screenshots.

## Strengths

- Able to learn independently and search for relevant documentation when working with unfamiliar technology.
- Capable of connecting frontend, backend, database, and cloud knowledge within one project.
- Responsible and persistent when testing and refining the product.
- Able to document the implementation process with reasonably complete explanations and screenshots.

## Areas for improvement

- Improve root-cause analysis when the system encounters complex issues.
- Communicate technical problems more concisely, accurately, and confidently.
- Develop deeper knowledge of security, monitoring, cost optimization, and system operations on AWS.
- Plan work in greater detail to balance development, testing, and documentation more effectively.

## Next steps

I will continue improving my skills in deploying and operating applications on AWS, with additional focus on monitoring, security, and automation. I also plan to use a more systematic approach to problem-solving, strengthen my presentation skills, and consistently document the lessons learned after each stage of a project.
