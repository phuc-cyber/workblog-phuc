# Tuần 4: Thiết kế bãi xe, vị trí đỗ và trạng thái vận hành

**Thời gian:** 01/06/2026 - 07/06/2026

## Mục tiêu

- Xây dựng mô hình dữ liệu cho bãi xe và từng vị trí.
- Quản lý trạng thái trống, đã đặt, đang có xe và tạm ngưng.
- Hiển thị sơ đồ bãi xe thống nhất giữa User và Admin.

## Công việc thực hiện

| Ngày | Nội dung |
| --- | --- |
| 01/06/2026 | Thiết kế bảng parking lot, zone và parking space. |
| 02/06/2026 | Xác định các trạng thái và điều kiện chuyển trạng thái. |
| 03/06/2026 | Xây dựng API lấy danh sách vị trí theo bãi xe. |
| 04/06/2026 | Phát triển sơ đồ và quy ước màu cho từng trạng thái. |
| 05/06/2026 | Kiểm thử khả năng đồng bộ trạng thái giữa database và giao diện. |

## Kết quả

- Có mô hình dữ liệu rõ ràng cho cấu trúc bãi xe.
- Giao diện thể hiện chính xác trạng thái của từng ô đỗ.
- User và Admin sử dụng chung một nguồn dữ liệu vận hành.

## Liên hệ sản phẩm

Sơ đồ bãi xe trên trang đặt chỗ và dashboard Admin được xây dựng từ kết quả tuần 4.
