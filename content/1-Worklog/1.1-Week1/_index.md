# Week 1: Problem Analysis and Car Parking Architecture

**Period:** 11/05/2026 - 17/05/2026

## Objectives

- Analyze limitations in manual parking operations.
- Define the two user roles and their main functions.
- Select technologies and draft the overall architecture.

## Activities

| Date | Work completed |
| --- | --- |
| 11/05/2026 | Reviewed reservation, entry/exit, parking-space state, and fee workflows. |
| 12/05/2026 | Defined User features: sign-in, booking, QR access, and history. |
| 13/05/2026 | Defined Admin features: dashboard, gate control, parking map, and audit logs. |
| 14/05/2026 | Selected Next.js, FastAPI, and PostgreSQL for the main application layers. |
| 15/05/2026 | Designed integration with RDS, S3, Cognito, Lambda, Rekognition, and CloudWatch. |

## Outcomes

- Completed the initial functional scope for Car Parking.
- Clarified the responsibilities of the frontend, backend, database, and AWS services.
- Produced an architecture model for the following development stages.
