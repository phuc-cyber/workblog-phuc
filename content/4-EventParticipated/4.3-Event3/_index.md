# Event 3: Cloud Architect Final & Technical Sharing

### General information

| Item | Information |
|---|---|
| **Event name** | Cloud Architect Final & Technical Sharing |
| **Time** | 09:00, 11/07/2026 |
| **Location** | 26th Floor, Bitexco Tower, 02 Hai Trieu Street, Saigon Ward, Ho Chi Minh City |
| **Role** | Attendee |

### Opening activity

The program began with the **Cloud Architect** final featuring **KLKAT** and **Ngu Dai Hiep**. Watching the competition allowed me to see how each team approached a cloud-architecture challenge, developed a solution, presented its reasoning, and defended its decisions before an audience.

### Sharing sessions

#### 1. Thinh Nguyen - Securing Your Web Apps With AWS Security Agent

This session explored the protection of web applications running on AWS. It gave me a clearer view of layered security, methods for reducing attack risk, and the importance of continuous monitoring for detecting operational issues early.

#### 2. Nguyen Huynh Son - SLA and Monitoring: From SLA to Monitoring What Really Matters

The speaker examined SLAs and the process of choosing meaningful metrics. I learned that effective monitoring goes beyond displaying dashboards: it must reflect user experience, system dependability, and operational objectives.

#### 3. Ngo Le Tan Huy - Inside The Exam: AWS Cloud Practitioner

This talk offered a practical overview of the AWS Cloud Practitioner exam, including ways to strengthen foundational knowledge, allocate study time, and plan an effective review process. The guidance increased my motivation to continue working toward an AWS certification.

### Value gained

The event strengthened my understanding of cloud-architecture thinking, web application security, objective-driven monitoring, and AWS certification preparation. It also gave me more practice in following presentations, taking selective notes, and organizing the knowledge shared in technical sessions.
