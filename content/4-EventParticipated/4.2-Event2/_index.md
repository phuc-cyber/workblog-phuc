### Sharing sessions

#### 1. Bao Huynh - Docker: A containerization technology

From this session, I learned how Docker packages an application together with the components of its runtime environment. This approach makes deployments more consistent across local machines, servers, and CI/CD pipelines.

#### 2. Le Hoang Gia Dai - Combining AWS WAF with Machine Learning for Cyber Attack Detection

The speaker demonstrated how Machine Learning can complement AWS WAF in identifying suspicious traffic and reinforcing web application protection. The session showed how data and analytical models can contribute to stronger security controls.

#### 3. Nguyen Quoc Bao - Multiplayer in the Cloud: Connecting Godot Clients with AWS WebSockets

This presentation described how Godot game clients communicate with a cloud backend through WebSockets. The example clarified the design of realtime applications, low-latency connections, and client-server architecture on AWS.

#### 4. Truong - Technical sharing session

The session gave me a useful example of breaking down a technical subject, organizing its presentation, and connecting the discussion to real use cases. It offered practical guidance for improving both problem analysis and technical communication.

#### 5. Viet Phat - AWS Neptune for Building a Graph Knowledge Base for GraphRAG

The speaker presented Amazon Neptune and the use of graph knowledge bases in GraphRAG. I gained additional insight into graph databases, relationships among entities, and the contribution of knowledge graphs to AI-assisted retrieval.

#### 6. Vinh Tran - From IT Helpdesk to Senior Sysadmin

From a career perspective, the session highlighted independent learning, documenting experience, and building a solid foundation in systems. The journey from IT Helpdesk to Senior Sysadmin illustrated how system-administration expertise develops progressively.

### Value gained

Event 2 broadened my perspective on Docker, web security, WebSockets, GraphRAG, and professional growth in system operations. It also gave me useful lessons on presenting technical material in a concise, accessible, and practical form.
